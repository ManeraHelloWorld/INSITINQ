# Media archive (used assets)

Сайт **не читает** эту папку в runtime.

Рабочие файлы лежат в `public/icons` и `public/images` — именно оттуда Next.js отдаёт картинки.

Эта папка — **архив переименованных копий** всех ассетов, которые реально используются в UI.
Её можно хранить как «чистый» набор исходников.

## Можно удалить без вреда для сайта

- `Иконки/`
- `Скрины макета/`

Они **не подключены** к коду. Удаление не сломает `npm run build` / `npm start`.

## Структура

```
assets/media/
  logo/           — логотип
  hero/           — баннер главной
  demo/           — превью продуктов
  team/           — фото команды
  icons/
    form/         — иконки полей заявки
    flags/        — флаги языков
    social/       — WhatsApp, Instagram
    industry/     — иконки отраслей
    team-roles/   — иконки ролей в карточках команды
    ui/           — прочее UI (globe)
  MANIFEST.md     — соответствие archive ↔ public
```

См. также `MANIFEST.md`.
